# Dot Link

Ce projet Android a été développé par Amir Kabbouri, Bamba Top et Athiran Nagathurai dans le cadre de la [SAE41_2024](https://iut-fbleau.fr/sitebp/sae4/41_2024/M852HZLDWTN26CVQ.php) lors de notre deuxième année (2024-2025) de BUT Informatique à l’IUT de Fontainebleau.

## Présentation du projet : 


Dot Link est une adaptation mobile du jeu "Flow Free". L’application propose une série de puzzles à résoudre, où le joueur doit relier des paires de points colorés sur une grille sans que les chemins ne se croisent. Le but est de remplir toute la grille.

Le projet est entièrement développé en Java pour Android, et respecte les consignes de l’énoncé : chargement de puzzles XML, navigation entre activités, gestion tactile, et prise en charge d’un mode achromate.


## Fonctionnalités

- Sélection dynamique des puzzles depuis le répertoire `assets/puzzles`
- Interface tactile pour tracer les chemins entre les points
- Vérification automatique de la solution
- Retour au menu, gestion de la pause, et verrouillage après victoire
- Mode achromate pour l’accessibilité
- Détection et désactivation des puzzles malformés
